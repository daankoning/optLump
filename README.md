# optLump

<!-- badges: start -->

[![R-CMD-check](https://github.com/daankoning/optLump/actions/workflows/R-CMD-check.yaml/badge.svg)](https://github.com/daankoning/optLump/actions/workflows/R-CMD-check.yaml)

The `optLump` package provides a function to optimally lump together
factor levels in a data frame. This can be useful for reducing the
number of levels in a factor variable, which can improve the fit and
interpretability of a model.
